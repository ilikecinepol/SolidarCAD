# Open CASCADE Technology

Текущая локальная сборка использует OCCT 8.0.1, полученный через vcpkg.
Для релиза сюда копируются без изменения:

- `LICENSE_LGPL_21.txt`;
- `OCCT_LGPL_EXCEPTION.txt`;
- применимые notices транзитивных компонентов сборки OCCT.

Исходные тексты текущего build tree находятся в исходном архиве порта OCCT;
release pipeline должен брать их из фактически установленного пакета, а не из
случайного локального build-каталога.
