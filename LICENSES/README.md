# Лицензии сторонних компонентов

Этот каталог резервирует стабильное место для канонических текстов лицензий,
которые входят в конкретный дистрибутив SolidarCAD.

- `Qt/README.md` описывает источник license bundle выбранной сборки Qt.
- `OCCT/README.md` описывает обязательные файлы лицензии и exception.

До создания release staging здесь не подменяются канонические тексты
пересказами. Release pipeline должен копировать тексты без изменений из
фактически используемых пакетов, затем проверять их хэши и перечислять в SBOM.
