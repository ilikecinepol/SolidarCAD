## Сознательные ограничения

- SBOM пока описывает прямые runtime-зависимости, а не полный бинарный staging.
- В `LICENSES/` не копировались случайные тексты из временного vcpkg build tree.
  Канонические тексты конкретных Qt/OCCT-пакетов должны копироваться без
  изменений release pipeline после формирования staging.
- Не добавлены CI, российское Git-зеркало и SBOM scanner: по плану это следующие
  инфраструктурные итерации.
- Юридическая квалификация лицензий требует проверки перед коммерческим
  релизом; текущие документы являются инженерным реестром, не заключением.
